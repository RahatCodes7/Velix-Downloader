FAQ

Which sites are supported?

YouTube (video, shorts, music → MP3/MP4), TikTok (HD, no watermark), Instagram (reel, post, story — public only), Facebook (video, reel — public only), Pinterest (video pin + image pin HD).

How to install as app (PWA)?

Android Chrome: menu ⋮ → Add to Home Screen / Install. iPhone Safari: Share → Add to Home Screen. Then it opens fullscreen like a native app + works from share.

Why does Instagram / Facebook private link fail?

Private / login-only / friends-only posts can't be fetched. Use a public link. Business/creator public reels work best.

Is it free? Quality?

Yes, free. YouTube via fast Shruti API (audio + video). Others via server: MP4 HD up to 1080p where available + 128k MP3.

Render hosting notes?

Deploy with Docker (ffmpeg + yt-dlp preinstalled). Free tier sleeps — first request may take ~30s. Downloads go direct from source to your device — server sudhu link toiri kore, file server diye jay na. Set SHRUTI_API_URL + SHRUTI_API_KEY env vars for fastest YouTube.
